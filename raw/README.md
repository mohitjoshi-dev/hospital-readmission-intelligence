# Raw Dataset Directory

This directory stores the local copy of the raw clinical dataset files (`diabetic_data.csv` and `IDS_mapping.csv`).

## Source
- **Publication**: Strack et al. (2014), *BioMed Research International*.
- **Source**: UCI Machine Learning Repository (Diabetes 130-US Hospitals, 1999–2008).

## Note
These files are intentionally excluded from the Git repository via `.gitignore`. See `data/raw/README.md` for full instructions.
